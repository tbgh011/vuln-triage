What is VulnTriage?

VulnTriage is an AI-powered vulnerability and CVE triage lookup tool built for security and development teams. Instead of wading through dense NVD advisories or raw scanner findings, you paste in a vulnerability and get back a structured, plain-English triage report in seconds.

It tells you what the vulnerability actually is, how an attacker would exploit it in practice, how risky it is given your specific stack and environment, and what to do about it — in priority order. It also notes how runtime protection, IAST, and SCA tooling would detect or block that class of vulnerability.

It runs entirely in the browser — no backend, no accounts, no data stored. Just your browser and the triage engine you pick: Google Gemini, Groq, or Microsoft Copilot. All three are free.

Getting started
1
Pick a triage engine
VulnTriage can triage with any of three engines, and none of them costs anything. Pick one with the Triage Engine switch just above the Analyze button — they work quite differently, so it's worth knowing which you want. Google Gemini — the report appears on this page Gemini is called directly from your browser, and VulnTriage renders the answer as a structured triage report right below the form: severity, exploitability, attack scenario, ordered remediation steps. This is the full experience, and it needs a free API key. Never made one? Follow these exactly:
  1. Go to aistudio.google.com/apikey and sign in with any Google account.
  2. Accept the Google AI Studio terms if you're prompted — this is a one-time step.
  3. Click Create API key. If it asks which project to use, pick Create API key in new project.
  4. Click the copy icon next to the key that appears. It looks like this:
AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
Unlike most API keys, you can come back to this page and copy it again later — it isn't a one-time reveal. Paste it into the key field under the Gemini tab. Groq — same report, usually faster Groq runs open-weight models (Llama, Qwen, GPT-OSS) on its own accelerators, and the free tier needs no credit card — just an account and a key. It renders the identical structured report on this page, normally in a second or two.
  1. Go to console.groq.com/keys and sign in.
  2. Click Create API Key, give it a name, and copy the value — it starts gsk_ and is shown once.
  3. Paste it into the key field under the Groq tab. The model list refreshes to whatever your account can use.
The free tier is rate-limited rather than billed, so heavy use gets throttled instead of charged. Microsoft Copilot — the report appears in a Copilot tab No key, no signup, nothing to configure. Fill in the vulnerability details as usual, then click Copy Prompt & Open Copilot. VulnTriage builds the same triage prompt it would send to Gemini, copies it to your clipboard, and opens Copilot in a new tab — paste with Ctrl+V (Cmd+V on Mac) and press enter.
  1. Choose Microsoft Copilot on the Triage Engine switch.
  2. Fill in the CVE, finding, or freeform description as normal — Fetch CVE works here too, since it reads the NVD rather than an AI engine.
  3. Click Copy Prompt & Open Copilot.
  4. Paste into Copilot's message box and send.
Why the paste step? Copilot has no API a web page is allowed to call, and its ?q= link parameter is discarded on load — so there is no way to push the prompt in automatically. The clipboard hand-off is the reliable substitute. It also means the structured report, the severity badges, and the remediation checklist are Gemini-only: with Copilot you get Copilot's own answer in its own tab.
2
Run the triage
With Gemini selected, paste your key into the field under the engine switch and hit Analyze Vulnerability — the report renders below the form. Your key is used directly in the browser and is never sent to any third-party server; it goes straight from your browser to Google's API. With Copilot selected there's no key field — the button becomes Copy Prompt & Open Copilot instead.
3
Pick an input mode
Choose the tab that matches your input:
CVE Lookup
Enter a CVE ID and hit "Fetch CVE" to auto-populate the description, or paste advisory text manually.
Security Finding
Paste a finding directly from your scanner or security dashboard — rule name, route, evidence, stack trace.
Freeform
Describe any vulnerability or security concern in plain language — pen test notes, incident reports, anything.
4
Add context for better results
The more context you provide, the more actionable the triage. In CVE mode, fill in your tech stack (e.g. Java Spring Boot 3.1, PostgreSQL) and set the exposure level. In Security Finding mode, add the app name, environment, and any notes about data sensitivity or authentication.
5
Click Analyze and read your report
Hit Analyze Vulnerability and your triage report will appear in a few seconds.

Tips
More context = better triage. Telling the tool your framework, whether the endpoint requires auth, and how sensitive the data is will produce a dramatically more useful risk assessment than a bare CVE ID.
Try the CVE Fetch button. Type any CVE ID and it pulls the official description, CVSS base score and attack vector straight from the NVD — no API key, and it works whichever engine you've picked. That saves you copying advisory text by hand, and gives the engine authoritative scoring to reason about. Anonymous NVD lookups are capped at 5 per 30 seconds; if you hit that, wait a moment and retry.
Privacy: Nothing you enter is stored anywhere. The app has no backend — your input goes directly from your browser to Google's Gemini API — or, with the Copilot engine, only to your own clipboard until you paste it.
